# Price Compare App

An Android application that allows users to compare 
product prices across multiple stores.

## Tech Stack
- Java, Android Studio, Firebase

## Features
- Barcode scanning for instant product lookup
- Multi-store price comparison and tracking
- Shopping list management
- User authentication and profile management
- Gamification module with themed levels and rewards

## Setup
1. Open project in Android Studio
2. Connect Firebase — add your google-services.json
3. Build and run on emulator or physical device
